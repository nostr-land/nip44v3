# Extensions to specifications

As NIP-44 v3 is not a drop in replacement for NIP-44 v2 due to backwards compatibility requirements and specific handling of `kind`/`scope`, extensions are needed to existing specifications.

The following extensions are currently defined:
- [NIP-07: `window.nostr`](./nip07.md)
- [NIP-17: Private Direct Messages](./nip17.md)
- [NIP-46: Nostr Remote Signing](./nip46.md)
